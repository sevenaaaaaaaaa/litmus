# UI 彻底整改方案（UI Overhaul Spec）

> 状态：P0–P3 全部实施 · 作者：ZCode · 2026-09-25
> 触发：用户指出「圆角无规范、顶栏与红绿灯冲突、页面信息大量重复、三模式定位不清、多端未规划」
> 本文是唯一整改依据；实施分四期（P0–P3），每期有验收标准。与 `design-system.md`（设计契约）、`PERF.md`（性能契约）并列，冲突时以本文为准。

---

## 0. 现状诊断（证据）

### 0.1 圆角失控（实测 index.html）

- 契约只有三档 token（`--r-sm/md/lg`，实际使用 28 处）；
- 但硬编码圆角 **15 种取值、80+ 处**：12px×12、8px×11、10px×11、9px×10、11px×9、16px×4、14px×4、13px×2、99px、999px×11、50%×12、3px×6……
- 后果：节点、面板、按钮、输入框、胶囊之间的圆角互不呼应，「精美感」的来源——一致性——被破坏。

### 0.2 信息重复清单（一信息多家）

| 信息 | 出现位置（应保留 ✗ 应删） |
|---|---|
| 库名 / 库根 | 面包屑 ✅ + 左下 foot ✗ + 状态栏连接区 ✗ |
| 文档统计（docs/indexed） | 左下 foot ✗ + 状态栏 ✅（唯一家） |
| 「新建文档」入口 | 左下「+新建」✅ + rail 顶部按钮 ✗ |
| 用户身份 | 状态栏 `seven@thirdchoice` ✅（唯一家）+ 右上头像按钮 ✗（点击行为并入） |
| 在线/连接 | 状态栏 `connected` ✅ + 状态栏「在线 1」✅（合并为一处） |
| 视图切换 | 顶部 画布/时间线/看板 ✅ + 旧 tab 镜头（全部/文档/采集/附件）→ 降级为画布过滤 ✗ 语义重叠 |
| Agent 入口 | 底部 dock 输入条 ✅ + 底部快捷 chips ✗（并入 slash 菜单） |
| 快捷键提示 | 状态栏右侧 ✅ + 空输入占位符 ✗ + 按钮 kbd 标 ✅（保留一处完整的） |
| Memo 入口 | 模式 seg ✅ + 左栏常驻面板 → 左栏改为模式驱动 Slot ✅ |

### 0.3 结构问题

- **导航三层语义混杂**：模式（七模式）× 视图（画布/时间线/看板）× 镜头（全部/文档/采集/附件），用户无法回答「我在哪、能去哪」；
- **左栏是四个功能的堆场**：Memo 面板 + 文档树 + 随手记输入 + 库统计，互相争空间；
- **右栏检查器常驻**，未选中时是 300px 的空壳；
- **底部三层横条**：dock 输入条 + 快捷 chips + 状态栏，压缩画布纵向空间；
- **顶栏与红绿灯打架**：浮动圆角工具条从红绿灯右侧开始，左端被切出两个视觉系统。

## 1. 设计原则（决策依据）

1. **一屏一事**：每个区域有唯一职责，禁多功能堆场。
2. **每个信息只有一个家**：展示它的唯一位置；其它出现即违规（审查清单见 §0.2，新增 UI 先查此表）。
3. **圆角即层级**：圆角大小表达「容器嵌套深度」，不表达「设计师心情」。三档 token + 一个 pill，全部走变量，代码里禁止裸 px。
4. **模式即布局**：切换模式 = 切换布局与工具集，而不是同一个布局上高亮不同按钮。
5. **触控优先的容差**：所有可点目标 ≥40px（桌面鼠标态允许 32px 视觉尺寸 + 扩展热区）。
6. **性能契约不受损**：所有动效仅 transform/opacity；渲染只发生在离散事件（PERF.md 纪律不变）。

## 2. 设计 Token（唯一规范）

```css
/* 圆角：四值，别无他选 */
--r-sm: 8px;    /* 内嵌小件：chip、kbd、tag、小按钮 */
--r-md: 12px;   /* 常规控件：按钮、输入框、菜单项容器 */
--r-lg: 16px;   /* 容器：面板、卡片、抽屉、浮层 */
--r-pill: 999px;/* 胶囊：面包屑段、分段控制器、状态点 */
/* 特例仅两个：圆形头像/圆点用 50%；进度条用 999px */

/* 间距：4pt 网格（4/8/12/16/24/32），禁止奇数间距（现存 9/11/13px 全部归并） */

/* 层级 z-index 表（唯一真相，现散落 40-400） */
--z-canvas:0; --z-rail:20; --z-chrome:30; --z-drawer:50;
--z-dock:40; --z-overlay:200; --z-present:300; --z-toast:400; --z-ctx:500;
```

**迁移规则**：`12px→var(--r-md)`、`8px→var(--r-sm)`、`16px→var(--r-lg)`、`9/10/11/13/14px→就近档`、`99/999px→var(--r-pill)`。一次 PR 全量替换（P0），后续 CI/审查按「裸圆角 = 违规」执行。

## 3. 信息架构重组

### 3.1 导航统一模型（回答「我在哪」）

```
顶栏（唯一全局导航，一行三段）：
┌──────────────────────────────────────────────────────────┐
│ [🔴🟡🟢] 库名 ▾   |   ⌘K 搜索…        |  Studio 学习 展示  |  Agent  ⚙  👤 │
└──────────────────────────────────────────────────────────┘
  系统区(immutable)   身份区              模式区(三主模式)      工具区
```

- **模式收敛为三个主模式**：Studio（创作）/ 学习（研读）/ 展示（演示）。整理 = Studio 的圈选工具态（进入方式：Studio 内按 M 或工具条按钮，不再是并列模式）；Memo = 学习模式的左侧 Slot + 全局快捷键 ⌘⇧M；RAG = ⌘K 检索态（搜索浮层即 RAG，不再是模式）；线上 = 发布动作（⌘⇧P 面板，不是模式）；Agent = 底部 dock（全局可用，不是模式）。
  - 依据：用户心智里「我在创作 / 我在研读 / 我在演示」是三种房间；其余都是房间里的工具。
- **视图切换（画布/时间线/看板）降级**：移出顶栏，成为 Studio 画布右上角的「视图胶囊」（它们只是 Studio 内的排布方式，出了 Studio 无意义）。
- **镜头 tab（全部/文档/采集/附件）降级**：并入侧栏顶部过滤行，与「过滤文档」合并为一行。

### 3.2 区域职责（一区一事）

| 区域 | 唯一职责 | 内容 |
|---|---|---|
| **顶栏** | 全局身份与模式 | 红绿灯区 / 库名+搜索 / 三主模式 / Agent·设置·头像 |
| **左栏（Slot 化）** | 当前模式的导航 | Studio→文档树+过滤；学习→目录大纲+Memo 热力图；展示→隐藏（全屏优先） |
| **画布** | 内容本体 | 节点/列表/文档，右上角浮「视图胶囊」（仅 Studio） |
| **右栏检查器** | 选中对象的操作 | **默认收起**，选中节点时滑出，Esc/点空白收起；与右键菜单同源动作 |
| **底栏（合并三层→一层）** | Agent 对话 + 状态 | 对话输入条（含 slash 菜单，吸收快捷 chips）+ 右端状态点（连接/统计/用户合一） |

### 3.3 顶栏与红绿灯的和解

- 顶栏改为**通栏贴顶**（不再是浮动圆角条），高度 48px，`env(titlebar-area-*)` 适配；
- 红绿灯位于通栏左端**同一行内**，左侧留 `env(titlebar-area-x)` 内边距；桌面端红绿灯区为拖拽区，导航按钮起为 `no-drag`；
- Web 端无红绿灯，同位置放「3C logo + 库名」，两端的视觉起点完全一致——冲突的根源是「浮动条 + 系统件」两个体系，通栏后消失。

## 4. 三模式差异化布局

### 4.1 Studio —— 面向创作（空间即画布）

- 保留：无限画布、景深、拖拽、多画布、圈选批量；
- chrome 最小化：左栏树可折叠成 56px 图标条；顶栏仅剩身份+模式；底部 dock 可整体收起（Tab 键）；
- 节点即对象：动作通过**节点动作栏**（已实现）与右键菜单，不在顶栏放节点级操作。

### 4.2 学习 —— 面向资料的有序组织（结构即路径）

- 布局从画布切换为**文档工作台**：左栏=目录树/大纲（Slot），中央=正文阅读（50 风格皮肤），右栏=该文档的元信息与反向链接（可选）；
- 顶部保留面包屑（唯一导航路径显示），画布交互全部让位于线性阅读；
- Memo Slot：热力图 + 标签快查 + 随手记（现在的左栏内容整体移入），默认折叠为一枚「Memo」入口，点开滑出。

### 4.3 展示 —— Gamma 式视觉优先（内容即画面）

- 进入即**全屏无 chrome**：无顶栏/侧栏/dock，仅底部悬浮控制条（翻页/风格/退出，鼠标静止 2s 自动隐藏）；
- 风格皮肤系统（50 款）为展示模式一等公民，切换在控制条内完成；
- 大纲侧栏：幻灯片缩略图纵向排布（Gamma 式），可收起。

## 5. 多端适配（Web / PC / Pad / 移动）

| 断点 | 布局 | 关键变化 |
|---|---|---|
| ≥1440（PC 宽） | 三栏全开 | 现状完整形态 |
| 1024–1440（PC 窄） | 三栏紧缩 | 左栏 240→220，检查器默认收起，顶栏搜索缩为图标 |
| 768–1024（Pad 横） | 两栏 + 抽屉 | 左栏改覆盖式抽屉（边缘滑出），检查器改底部抽屉；触控目标 ≥44px |
| 768–1024（Pad 竖） | 单栏 + 底部导航条 | 模式切换移到底部 tab（Studio/学习/Memo/Agent 四枚） |
| <768（移动） | 单栏 + 底部导航 | 画布改纵向列表流；对话全屏化；手势：左缘右滑=开导航，双指缩放保留于画布 |

- 统一触控规范：可点目标 ≥44×44、间距 ≥8px；hover 效果在 `(hover:none)` 下全部禁用；
- 桌面独占能力（全盘导入、本地模型）按 `desktop_mode` 门禁在移动端隐藏，不出现在能力表之外。

## 6. 实施分期（每期独立可发布，SW bump + perf-check 必跑）

### P0 —— Token 统一 + 去重（1 个 PR，低风险高观感）
- 全量替换 15 种裸圆角 → 四 token；奇数间距归并 4pt 网格；
- 删除 §0.2 表中所有 ✗ 重复位（状态栏成唯一统计家、单一新建入口、chips 并入 slash）；
- z-index 收敛为变量表。
- **验收**：仓库内 `grep 'border-radius:[0-9]'` 为 0；重复信息表逐条复查通过；性能门禁全绿。

### P1 —— 导航与布局重组
- 顶栏通栏化 + 红绿灯和解 + 三主模式收敛（整理/RAG/线上/Agent 降级为工具态）；
- 左栏 Slot 化、检查器默认收起、底栏三层并一层。
- **验收**：「我在哪」测试——任一截图能 3 秒内指出当前模式与位置；空白画布可用面积 ≥ 现在 +18%。

### P2 —— 三模式差异化
- 学习模式文档工作台布局；展示模式全屏 + Gamma 式缩略图侧栏 + 控制条自动隐藏；Studio 视图胶囊。
- **验收**：三模式布局互不相同且各自切换 ≤300ms；展示模式无任何常驻 chrome。

### P3 —— 多端
- 断点表落地 + Pad/移动导航形态 + 触控规范。
- **验收**：375/768/1024/1440 四宽截图审查；触控目标抽检 ≥44px；移动端首屏可交互 <2s（SW 命中）。

## 7. 风险与守护

- **不是重写**：P0–P3 全部在现单文件前端内增量改造，任何一步可独立发布与回滚；
- **性能红线**：改版不新增常驻监听；断点切换用 CSS media query 而非 JS 重排（PERF.md 纪律）；
- **桌面同步**：每期合入后重打 dmg 并随版本发 Release（桌面 UI = 构建时快照的既定机制）；
- **审查方式**：每期完成后用真实浏览器按「模式 × 断点」矩阵截图，对照本文验收。

## 8. 三层材质与面板状态（2026-10-18）

> 触发：五个区域（顶栏 / 左导航 / 画布 / 右预览 / 底栏）全部保留，但它们都是「浮起的圆角卡片」，视觉层级打平、画布显挤。

### 8.1 三层材质

| 层 | 成员 | 规则 |
|---|---|---|
| 外框 | 顶栏 `#chrome`、底栏 `.dockbar` | 贴窗口边，无圆角无阴影，磨砂底 + 发丝线 |
| 面板 | 左导航 `#rail`、右预览 `#inspector`、文档抽屉 `#drawer` | 宽屏（>1024）贴住外框与窗口边，同一材质 `--panel-bg`，发丝线分隔，不用卡片阴影 |
| 内容 | 画布卡片 `.node` | 唯一带圆角与阴影的层；类型只由图标瓷片表达（去掉顶边彩条） |

≤1024 仍沿用原覆盖式抽屉 / 底部抽屉（§5）。

### 8.2 每个信息一个家（本轮落实）

- **当前位置**：面包屑并入顶栏（`库名 / 路径 · N 篇`），画布上方浮动胶囊删除；
- **侧栏开关**：只留底栏左端按钮 + `⌘\` + 左缘悬停，顶栏 `#rail-toggle` 隐藏；
- **左栏底部 = Memo 日历**：Memo 与日历合一——月历格子深浅即当天 Memo 数，圆点为当天改动的文档；点日期 → 当天 Memo（无 Memo 则回落到当天文档）；
- **工具**：移出左栏，归 Magic 扇面「采集」（采集主题 / 网页本地化 / 连接器 / 插件命令）；发布仍在 ⋯ 菜单与文档抽屉；
- **底栏状态**：Token / 在线 / 同步收进头像状态簇（同步灯、协作人数做角标），点开看详情与进入设置。

### 8.3 面板两种状态

- **固定**：底栏开关或 `⌘\`，画布 `fit()` / 选中定位（`canvasInsets()`）让出面板宽度；
- **临时**：左栏收起时鼠标贴左缘 160ms 滑出，浮在画布上（带阴影），指针越过面板右缘 24px 自动收起；临时态下点开关 = 固定；
- **右预览**：选中节点时若被检查器遮住，画布自动平移把它请出来（`revealNode`）；动作改为一行幽灵图标钮，空区块不占位。

## 9. v4 精修：配色与圆角的用法纪律（2026-10-19）

> token 本身（oklch、对比度测试）已经完整；问题出在「怎么用」。本节规定用法，`server/tests/craft.rs` 守护圆角。

### 9.1 颜色

- **石蕊红（`--accent-2`）只给 AI 与品牌**：Agent 火花、AI 回复署名、思考光、Magic 宝珠、品牌渐变。结构（文件夹、树图标、选中竖条）、状态（日历热度、协作人数、对齐线）一律用 `--accent` 或中性色；
- **文件夹是中性的**：`--kc: var(--text-2)`，文档蓝、采集绿、附件黄、视图紫保留为类型识别；
- **标签 = 中性胶囊 + 6px 色点**：色相只做识别不做底色，两主题下对比度一致；
- **氛围光克制**：`--blob-*` 透明度减半以下，画布顶部光晕 9% → 5%，卡片对比度优先。

### 9.2 圆角

- 五档 token：`--r-xs 3`（标记：光标、选区、热度格、kbd）/ `--r-sm 8` / `--r-md 12` / `--r-lg 16` / `--r-pill`；
- **嵌套规则**：内层圆角 = 外层圆角 − 内边距。16 的卡片里放 8 的图标块，12 的面板里放 8 的控件；
- `<style>` 与静态标记只许出现 token、`0`、`50%`（`craft.rs::radii_come_from_the_token_scale`）。阅读风格预设与导出模板是内容样式，不受此限。

### 9.3 卡片

- 卡片是纸：去镜面高光与竖向渐变，阴影两层（1px 接触影 + 柔和环境影）；文件夹只留一层纸边；
- 选中：强调色描边 + 18% 外环；
- 信息密度：路径行只放标题之外的信息（所在文件夹；文件名与标题不同才显示），页脚只放相对时间；
- 等宽字体只给路径、代码、快捷键；计数与时间用正文字体 + `tabular-nums`。
