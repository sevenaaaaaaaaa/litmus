# Consistency Spec — 文件真相 + op-log 并发真相

状态：已采纳（2026-09-18，ADR-0002）

## 不变量

1. `Notes/` 与 `Assets/` 下的文件是**内容真相**。任何工具（Obsidian/VSCode/vim）可直接编辑，内核必须无损跟随。
2. `.litmus/local/ops/` 内的 Automerge 文档是**并发真相**。多端并发编辑在此合流。
3. 两个真相通过确定性序列化（kernel-md `to_markdown`）互译。同一块模型永远产出字节相同的 MD。
4. 崩溃安全：所有落盘先写 `.tmp` 再 `rename`，无半写状态。
5. 无变化不写 op：导入时与现有模型比对，相同则跳过，防止 op 膨胀。

## 状态机

```
外部改文件 ──parse──▶ 块模型 ──diff──▶ ops 追加 ──▶ 持久化 .litmus/local/ops/
远端 ops 到达 ──▶ op-log 合并 ──物化──▶ 确定性 MD ──▶ 覆写文件
两侧同时变 ──▶ CRDT 字段级合并 ──▶ 物化（文件收敛到合并结果）
```

## 物化规则

- 物化前先比对：文件内容 == 物化结果时跳过（尊重文件现状，避免 mtime 抖动）。
- 物化输出是**规范形态**：首次物化可能重排用户手写格式（如 `*` 列表 → `-`），这是特性而非缺陷——git diff 一次性规范化，之后稳定。

## 图片/附件

- 文档内引用标准相对路径 `Assets/ab/cd/<sha256>.png`（Obsidian 可直接解析）。
- 引用登记表维护 hash → 别名 → 图床 URL 映射；换图床不改文档。

## 已知边界（Phase 0 接受，Phase 1 解决）

- 解析器为行级往返保真，非完整 CommonMark；无法结构化的内容进 Raw 容器。
- op-log 当前为快照格式，增量变更流（真正的 append-only log）在同步协议落地时切换。
