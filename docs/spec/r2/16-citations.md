# P1-11 · 证据与三色引用

> 从 Phase 2 前移到 Phase 1 的第一件事。理由是它是**数据结构**，不是功能：晚做等于把"来源"当装饰补上去。

## 目标（看板原话）

> 直接 / 转述 / 推断三色；无来源给固定文案；每条结论可点回块锚点。

## 数据契约

一条 AI 结论 = 一段话 + 若干条引用；每条引用指向一个**块锚点**（和灵魂卡同一套语法，直接复用 P1-01 的解析）。

```json
{
  "id": "c1",
  "text": "判断是被反复使用过的取舍，不是结论。",
  "citations": [{ "anchor": "note-a-1", "kind": "direct", "quote": "是被反复使用过的取舍" }]
}
```

| 类型 | 含义 | 机器怎么验 |
|---|---|---|
| **直接引用** `direct` | 逐字出现在源块里 | 必须带 `quote`，去掉空白后必须是源块文本的子串，否则 `quote-not-in-source` |
| **转述** `paraphrase` | 来自源块，但换了说法 | 只验锚点存在；**不能**单独把结论升成"有据" |
| **推断** `inference` | 模型自己推的 | 只验锚点存在，并且必须打「含推断」标签；**永远不算证据** |

## 关键设计：三种失败不能合并成一句话

这是这轮最重要的决定。原来的写法是"没有引用 → 没有找到来源"，但实测下来会把三种完全不同的情况说成同一句话：

| 状态 | 什么时候 | 界面说什么 |
|---|---|---|
| `ungrounded` | 一条引用都没有 | **没有找到来源**（固定文案，一字不改） |
| `broken` | 有引用，但锚点不存在 / 引文对不上 / 类型非法 | **来源对不上** + 逐条列出哪里对不上 |
| `weak` | 只有转述 | 只有转述（弱来源） |
| `inferred` | 只有推断 | 只有推断 + 「含推断」标签 |
| `grounded` | 至少一条逐字命中的直接引用 | 有据 |

把 `broken` 说成"没有找到来源"是**撒谎**：它明明有锚点，只是引文对不上。用户据此判断"能不能信"，所以这句话不能省事。

## 顺手修的一个跨模块 bug

跑全量测试时 P0-07 的队列测试红了：`drain()` 按文件名排序，而文件名是 `createdAt + "\-" + id`——**同一毫秒的两条会按哈希排**，于是"先入先出"其实是"哈希序"。测试原来靠运气过。已改成按 `createdAt` 排序、同刻用 id 打破平手，并把这个约定写进测试名。

这件事本身是一条产品结论：**不要让文件名暗示顺序**。队列的顺序必须由内容字段决定。

## 已知边界

- **没有接真模型**：校验器是确定性的，输入是已生成好的 claim 列表。接模型是 P1-05 的事。
- **转述无法真正验证**：只验锚点存在，"换了说法"是否忠实要人看。所以它被降级为弱来源。
- **跨语言引用**：中文逐字比对可行，英文大小写/标点差异还没处理。
- **引用单元只有块锚点**：整篇引用、页级引用、外部 URL 都还没进模型。

## 新思路

1. **`weak` 应该阻断"成稿"，只允许继续推进。** 现在它只是个标签；如果弱来源能直接发出去，三色就退化成装饰。建议：发布面板里 `weak` 需要一次显式确认，`broken` 直接禁止。
2. **推断不是错误，是待办。** 现在「含推断」只是一个标签，用户看完就忘。给推断一个主动作「找证据」，把它送回推进闭环——三色就从"警告系统"变成"工作流"。
3. **固定文案要三句，不是一句。** 状态已经分了四种，文案还只有"没有找到来源" + 一句提示。缺的是：引文对不上时说什么、只有推断时说什么。文案是产品的一部分，不能靠渲染层临时拼。
4. **图标 13px 太小，撑不起灰度可读。** 三色里"直接引用"（蓝）与"转述"（深灰）在灰度下几乎一样；打算再加一层形状差异（实线 / 虚线 / 点线），而不是继续加颜色。
5. **引用失败应该被统计。** 现在 `quote-not-in-source` 只是报错；如果按模型统计它，就是一个真正的幻觉率指标——比"AI 接受率"更接近用户关心的东西。这条应该进 P0-02 的指标表（第 11 个指标）。

## 对后续的影响

- **P1-05 推进闭环**：连回来源时写的就是 `^anchor`；确认落盘前先跑一次 `verifyClaim`，`broken` 不许落盘。
- **P2-02 矛盾检测**：直接复用 `broken` 与 `weak` 两种状态，不再另造一套"可信度"。
- **P1-10 临时卡**：临时卡产生的 AI 输出必须带三色，否则"未确认"只是一个没有内容的口号。
