# P1-07 ·「像我」盲评机制 v1

## 目标

> 10 段模板 + 评分表 + 判定。两个评审独立打分；分歧 > 1 分时有裁决规则。

要解决的问题很具体：**“像不像本人”不能由作者自己说。** 作者看自己写的东西，永远觉得像；模型看自己生成的东西，也永远觉得像。盲评把这件事变成两个不知道对方分数的人各打一次分，再用一条写死的规则处理分歧。

## 机制

| 环节 | 做法 | 落在哪 |
|---|---|---|
| 材料 | 同一份灵魂卡，按 10 个角度各写 80–120 字；随机排序、不标来源 | reference/p1-07-review/template.md |
| 打分 | 两位评审独立打 1–5 分，每段先写一句理由（≥10 字） | reference/p1-07-review/rubric.md |
| 分歧 | 分差 ≤1 取均值；=2 第三人盲评取中位数；≥3 或第三人把极差拉到 ≥3 → 无法判定 | review.mjs 的 scoreSegment |
| 整卷 | ≥7 段达到 4 分且无待裁决/无法判定 → pass；≥4 段 → revise；否则 fail | review.mjs 的 judge |
| 一致性 | 二次加权 Cohen's κ（1–5 分，k=5） | review.mjs 的 weightedKappa |

十段不是随便凑的：判断、审美、边界、反例、工作方式、关系、句法、记忆、时间观、未知。前六个测“取舍”，第七个只测“怎么说”，后三个测“会记住什么 / 什么值得等 / 敢说不知道”。

## 判定规则为什么长这样

- **分差 ≤1 取均值**：相邻两档的差别本来就模糊，不值得为 0.5 分开会。
- **分差 =2 才请第三人**：差 1 分是尺子刻度问题，差 2 分是“一个觉得像、一个觉得不像”，必须有人破平。
- **第三人取中位数，不取均值**：均值会把 1 和 5 折成 3，看起来“通过”，实际两人都没被说服。中位数至少保留了多数意见。
- **极差 ≥3 直接无法判定**：三个人给出 1/3/5，说明这段根本没有共识；硬算一个分数只会把它送进“通过”里。
- **κ 只说明尺子一致**：κ 高但分数低，仍然不通过；κ 低先对齐锚点再重评。

## 没做的

- **没有真实评审数据。** 现在只有机制与合成样例；真正的两位评审要等人（或两个互不可见的 agent 各跑一遍）。κ 的 0.6 阈值来自惯例，没有用真实样本校准过。
- **没有做评审界面。** 目前是 JSON 输入、命令行输出；做成卡片界面前，先让机制在真实材料上跑两轮。
- **没有防止“两位评审是同一个人”。** 机制要求独立，但无法证明独立；只能在流程上要求分开、不交流。

## 新思路

1. **产品：把“像我”拆成“取舍像”和“句法像”两组。** 前六段测取舍，第七段只测句法；如果取舍分高、句法分低，说明灵魂卡内容对但声音没学到——这比一个总分有用。
2. **实现：κ 应该按“段”算，不按“整卷”算。** 现在 κ 是 10 段合起来算；如果只有一段分歧很大，κ 会被其他 9 段稀释。下一步可以输出逐段分歧图，直接指出“哪一段的尺子不一致”。
3. **计划：裁决人也会疲劳。** 第三人盲评听起来公平，但如果每卷都有 3–4 段要裁决，第三人会开始偷懒（直接给中间分）。规则应该限制“每卷最多裁决 3 段”，超过就整卷重评，而不是继续加人。

## 对后续的影响
