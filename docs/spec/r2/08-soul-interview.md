# P0-08 · 灵魂卡访谈脚本 v0

## 目标

> 灵魂卡访谈脚本 + 3 个设计伙伴试跑。验收：10 分钟完成。

## 做了什么

产物：[questions.json](reference/p0-08-soul-interview/questions.json) · [run-interview.mjs](reference/p0-08-soul-interview/run-interview.mjs) · [记录表.csv](reference/p0-08-soul-interview/记录表.csv)

| 区块 | 问题 | 秒 | 追问 |
|---|---|---|---|
| 我相信 | 有没有一件事，你反复用它做判断，但从来没写下来过？ | 90 | 如果有人说反了，你会当场反驳哪一句？ |
| 我如何判断 | 你砍掉一个想法时，通常看什么？给我三条。 | 120 | 上周你否掉的哪件事，是按哪条否的？ |
| 我拒绝 | 有什么是你坚决不写的？ | 90 | 最近一次你忍住了没发，是因为什么？ |
| 我的声音 | 给我三段你自己满意、又能代表你的旧文字。 | 150 | 哪一段最像你？为什么不是另外两段？ |
| 我在追的问题 | 最近一年，你反复回到哪个问题上？ | 90 | 如果这个问题被回答了，你的作品会变成什么？ |
| 我的读者 / 作品 | 你写给谁看？希望他们拿走什么？ | 60 | 他们会用什么话把你的东西转给别人？ |

**四条规则**：每个问题先给 2–3 个候选，用户只做「像我 / 改写 / 删掉」；候选必须来自用户自己的文字或原话；沉默超过 8 秒就跳过并记 `skipped`；全程不写盘，确认后才写 `Notes/灵魂卡.md`。

**放弃判定**：任一问题连续两次 skipped → 记为「临时灵魂卡」，AI 输出上标「未确认」。

## 验证

`bash node p0-08-soul-interview/run-interview.mjs` 打印带时间轴的台本（`--compact` 只打问题），合计 10:00。记录表可直接给伙伴填。

## 卡在哪

- **3 个设计伙伴试跑：0/3 做了。** 这一项需要真人，本轮没有。台本本身可验证，但"10 分钟真的够吗"仍然未知。
- 时间表算得很满：90+120+90+150+90+60 = **600 秒整**，零缓冲。任何一个问题多聊两句就会超时。

## 新思路

1. **10 分钟是纸面数字，真实排期应按 15 分钟。** 留 3 分钟给开场、确认与"改一个词"。对外承诺仍然可以说 10 分钟，但内部排期按 15 分钟，否则每次试跑都"失败"。
2. **候选由 agent 生成 = agent 写的卡。** 如果候选不是从用户自己的文字里抽出来的，用户只是在给 agent 的句子点赞。访谈式必须只用**用户刚才的原话**做候选；提炼式必须标出"来自哪一段"。
3. **用户最抗拒的不是问题，是"被总结"。** 每个候选都要能回答"这句话里哪个词是你的"。允许只改一个词，参与感就够了。
4. **临时卡必须能一键升级。** 跳过的人会拿到"未确认卡"，如果没有一个显眼的"把它变成真的"入口，他们会永远停在临时状态，而所有 AI 输出都带着免责标注——体验上等于半个残废。
5. **盲评 10 段成本太高。** 先做 5 段 × 2 轮，看两轮能否拉开差距；能拉开再加到 10 段。评审要给"哪段不像人写的"而不是"哪段像本人"，后者更容易被礼尚往来污染。

## 对后续的影响

- P1-01 灵魂卡数据模型必须支持"临时卡"这个状态（`confirmed: false`），不能只有"有卡/没卡"。
- P1-07 盲评从 5 段起步。
