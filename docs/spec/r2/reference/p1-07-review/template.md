# 「像我」盲评 · 10 段模板

> 用法：把同一份灵魂卡交给写手（人或模型），按下面 10 个角度各写一段 80–120 字。
> 十段混在一起、随机排序、不标注来源，再交给两位评审独立打分。
> 目的不是选“最好的一段”，而是找出**哪一段换个人也能写**。

## 写作约束（对所有段一致）

- 每段只回答一个角度，不写成宣言，不用“我是一个……”开头。
- 必须能指回灵魂卡的具体锚点（2–3 条），写作时把锚点写在段末的括号里，评审时隐藏。
- 不许使用形容词自夸（“敏锐”“有洞察力”“独特”）。
- 允许说“不知道”“还没想清楚”；这不算扣分项。
- 每段 80–120 字；超过 160 字视为跑题。

## 十段

| # | id | 测什么 | 灵魂卡来源（区块） | 这一段要看到的具体东西 |
|---|---|---|---|---|
| 1 | judgment | 判断 | 判断 / 价值 | 面对一个模糊选择时，先看什么、放弃什么、为什么 |
| 2 | taste | 审美 | 审美 / 偏好 | 看到一版设计或一段文字的第一反应，具体到哪一处刺眼 |
| 3 | boundary | 边界 | 边界 / 不做 | 什么情况下会拒绝；拒绝时怎么说，不绕弯 |
| 4 | counter | 反例 | 反例 / 不确定 | 主动说出自己可能错在哪，不表演谦虚 |
| 5 | workstyle | 工作方式 | 工作方式 / 节奏 | 一天怎么开始；卡住时是换路、停下还是硬推 |
| 6 | relation | 关系 | 关系 / 协作 | 怎么对待合作者或朋友的不同意见；什么时候坚持 |
| 7 | language | 句法 | 声音 / 语言 | 常用句式、断句、口头禅（只看怎么说，不看说什么） |
| 8 | memory | 记忆 | 记忆 / 细节 | 会记住什么细节；为什么是这一处而不是别处 |
| 9 | time | 时间观 | 时间 / 取舍 | 长期与短期怎么权衡；什么值得等 |
| 10 | unknown | 未知 | 未知 / 边界 | 明确说“我还不知道”的领域，以及怎么面对它 |

## 评审怎么拿到材料

1. 十段按随机顺序编号（A–J），不带 id、不带锚点、不带作者。
2. 两位评审拿到同一份材料，**分开打分，不交流**。
3. 先读灵魂卡，再读十段；每段先写一句理由（≥10 字），再给 1–5 分。
4. 打完不改分。要改，必须重打整卷，并在理由里写清为什么。

## 不算数的做法

- 一位评审打完，另一位“参考一下”。
- 只打总分，不写理由。
- 用作者自己的判断替代评审。
- 把“写得漂亮”当成“像本人”；这两件事经常相反。
