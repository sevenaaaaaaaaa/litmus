# 「像我」评分表 v1

## 1–5 分怎么定

| 分 | 锚点 | 判断句 |
|---|---|---|
| 1 | 完全不像 | 这段话换任何人都能写，且没有一条能指回灵魂卡 |
| 2 | 有点像，但只是主题像 | 观点方向对，措辞和取舍是通用的 |
| 3 | 说不准 | 有一两处像，但整体可以用另一个人的卡写出来 |
| 4 | 像 | 能指出具体相似处：某个取舍、某句断法、某个不该省略的细节 |
| 5 | 很像 | 能说出“这就是他会说的话”，且能指回 2 条以上锚点 |

## 打分步骤

1. 读灵魂卡（六区块 + 锚点），不超过 10 分钟。
2. 读十段（随机顺序），每段先写一句理由，再给分。
3. 理由必须落在具体处：哪个词、哪个取舍、哪条锚点；不接受“感觉像”。
4. 打完封存，交给汇总脚本。

## 分歧与裁决

- 两位评审分差 **≤1**：取均值，记为 agreed。
- 分差 **=2**：第三人盲评该段（不知道前两人的分），取三人中位数，记为 arbitrated。
- 分差 **≥3**，或第三人把三人极差拉到 **≥3**：记为 undecidable，该段回炉。
- 回炉段必须换素材或换写法；只改标点、换同义词不算重写。

## 整卷判定

- pass：10 段里 ≥7 段达到 4 分，且没有待裁决段、没有无法判定段。
- revise：≥4 段达到 4 分，无法判定段 ≤2。
- fail：其余情况。
- 有待裁决段时，整卷停在 needs-arbitration，不给结论。

## 一致性指标

二次加权 Cohen's κ（1–5 分，k=5）：

- κ ≥ 0.6：两位评审的尺子基本一致，分数可采信。
- 0 ≤ κ < 0.6：尺子有分歧，先对齐锚点再重评。
- κ < 0：比随机还差，这一轮作废。

κ 只说明“尺子一致”，不说明“像不像”；判定仍以分数与理由为准。

## 反自欺条款

- 评审不能看到对方的分数，也不能看到汇总结果后再改分。
- 作者不能当唯一评审；作者可以打，但必须有一位独立评审。
- 任何一段的分数必须附理由；没有理由的分数按缺失处理，不补默认分。
- “像”不等于“好”。一段写得差但很像，仍然是 4 分；写得漂亮但谁都能写，仍然是 2 分。
