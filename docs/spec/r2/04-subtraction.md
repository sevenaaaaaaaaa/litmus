# P0-04 · 减法清单 v1

## 目标

> 顶栏四个视图 tab → 镜头控件；常驻检查器 → 卡背；「更多」菜单 → ⌘K + 设置；三个入口 → 一个「空间」抽屉。
> 验收：任一截图 3 秒内能回答「我在哪、这张卡是什么状态、下一步是什么」。

## 四项收敛

| # | 现在 | 改成 | 保留什么 | 用户会丢什么 | 怎么退回 |
|---|---|---|---|---|---|
| 1 | 顶栏常驻「画布 / 文档 / 时间线 / 看板」四个 tab | 画布内镜头控件 ⌘1–4，顶栏只显示当前镜头名 | 四个视图全部能力；⌘K 里可搜到 | "一眼看到还有别的视图"的可发现性 | 镜头控件旁留一个「全部视图」下拉；三个月后看点击率再决定去留 |
| 2 | 常驻检查器面板 | Space 翻开卡背 | 来源/历史/关系/操作 | 同时改多张卡属性的效率 | 多选时临时恢复为侧栏（多选是"批量"场景，不是"看一张"场景） |
| 3 | 「更多」杂物菜单 | ⌘K 命令面板 + 设置 | 所有命令 | 老用户的肌肉记忆 | 保留一个「⋯」按钮，点开只教你「按 ⌘K」；三个月后移除 |
| 4 | 左栏文档树 / 文档库 / 画布文件夹三个入口 | 一个「空间」抽屉（⌘） | 三种粒度：空间 / 线索 / 卡 | "我在哪个库"的空间感 | 抽屉顶部保留面包屑；面包屑可点回 |

**不删**（用户已认可，写进规划 §3.4）：画布首屏、Dock、⌥右键、文档模式、绿纸、无影卡片、Memo、日历、发布、MCP。

## 每项的验收

1. **镜头**：截图里没有 tab 条，但能在一次按键内换视图；换视图不丢选中。
2. **卡背**：单卡操作 1 次按键可达；多选时属性面板仍在。
3. **⌘K**：所有被删菜单项都能在命令面板里搜到同义关键词（用旧名字能搜到）。
4. **空间抽屉**：任意深度都能看到自己在哪个空间；⌘ 一按即开。

## 新思路

1. **减法真正难删的是"位置记忆"。** 用户用"左边第三个"记功能，不是用名字。改版必须给一次"它搬到哪了"的显式引导（点旧位置 → 高亮新位置），否则会被当成功能丢了。
2. **"镜头"会自己长成新的 tab 条。** 必须写死上限：4 个镜头、不进顶栏常驻、不允许插件加镜头。否则两年后又是四个 tab。
3. **检查器变卡背，把"改属性"从一步变两步。** 需要一条"选中即改"的轻路径（选中时卡旁出现一条状态/标签的快捷编辑），否则高频改标签的人会骂。
4. **⌘K 的前提是能被发现。** 命令面板是"知道的人才知道"的入口。建议：前三个月每次用鼠标点旧位置，弹一次"按 ⌘K 更快"的提示，一生只弹三次。
5. **减法没有度量就是赌博。** 现在没有"入口使用率"事件，删哪个全靠直觉。应加 `ui.entry_used`（入口 id + 次数，不含内容），删之前先看四周数据。这一条我建议进 P1 的埋点增补。

## 对后续的影响

- P0-05 的卡解剖必须假设"没有常驻检查器"，所以卡背要能承载全部属性。
- P1-03 五动作的快捷键表以本清单为准（⌘1–4 归镜头，Space 归卡背）。
