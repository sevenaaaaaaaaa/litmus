# 魔法排版 · 自动命名 · 公开分享

## 魔法排版（`kernel-md::tidy` + `POST /doc/tidy`）

复制来的文字（网页 / Word / 飞书 / PDF）常见的格式损坏，规则引擎离线识别并修复，**只动格式不动字**、代码块不碰、二次运行无变化。

| 问题 | 修法 |
|---|---|
| 多行挤成一段 / 句子被硬换行打断 | 逐行判断：行尾是逗号或满行不收句 → 接上；收句或短行 → 分段 |
| 条目挤在一段（1. 2. 3. / ①②③ / • •） | 拆成列表，前导语独立成段 |
| 标题丢失标记（第X章 / 一、/（一）/ 1.1） | 按出现的编号体系依次分配 ## / ### / #### |
| 缺少文档标题 | 首行短句（无句末标点）提升为 # |
| 表格未识别（制表符 / 多空格对齐 / 管道无分隔行 / CSV）、列数不齐 | 还原为 Markdown 表格并补齐 |
| 序号不连续（空行隔开 / 1、2）(3)） | 合并为一个列表并顺序编号 |
| JSON / 代码 / 命令行 / 流程图 / 公式未成块 | 进 ```json（保序缩进）/ ```lang / ```mermaid / $$ |
| 链接失效 | `[字] (url)` 修正、裸 www 补协议、URL 紧贴中文补空格 |
| 字间空格、多余空格、全角数字、零宽字符、不换行空格、页码残留、大面积空行 | 清理 |

- `mode: diagnose` 只体检（打开文档时自动跑，≥3 处才提示）；`rule` 规则修复；`ai` 规则后交给模型（无工具的纯补全），逐块做内容保真校验（去掉空白与记号后字符重合 ≥ 96%），不过关的块退回规则结果。
- 渲染补齐：`$…$` / `$$…$$` 公式（KaTeX）、```mermaid 流程图、单独成段的视频链接（YouTube / Bilibili / Vimeo / mp4）内嵌播放。外部脚本只在文档用到时按需加载。

## 自动命名（`POST /doc/autoname`，保存后调用）

- 一级标题（或 frontmatter `title:`）即文件名：只替换文件系统非法字符，保留中文、大小写与空格；重名追加序号；改名后同步改写 `[[旧名]]` 双链。
- 没有标题、且文件名是占位（未命名 / Untitled / 时间戳 / note-xxx）时：配了模型用 AI 起名，否则取首句；占位 H1（`# 未命名`）一并替换。

## 公开分享（`POST /publish`）

- 配置了公网目标（`default_target` 或唯一的 git / s3 / cf-pages 目标）时，把这一页写进目标站点的 `share/` 并推送，返回 `public_url`（`public_base_url` 或 `publish.base_url` + `/share/<slug>.html`）。
- 没有公网目标时明确告知「仅本机可见」，提供「下载 HTML 发给别人」（库内图片已内联为 data URI，单文件可离线打开）与「配置公开发布」两条路；在自建服务器上打开时本地链接即公网链接。
