# 画布优先的内容工作区

> 2026-10-26：下一代默认壳「知识场」已作为试用与本壳并存，见 `field.md`。本文继续约束经典壳；知识场成为默认（F2）时，本文的信息结构部分由 `field.md` 接替，「入口迁移必须有可见替代路径」一条继续适用。

2026-10-25，Dock-first 修订。默认首屏为画布 + 底部统一 Dock，撤销此前“顶栏 AI 助手 / 右侧聊天浮窗替代 Dock”的规则；与旧规范冲突时以本节为准。本次是交互革新与视觉升级，不是功能精简。现有能力、数据格式与完整操作流程必须保留，入口迁移必须有可见替代路径，不能仅以代码仍在或快捷键可用作为保留依据。

## 信息结构

默认进入思考画布，桌面与手机一致。可退场的顶栏保留画布、文档、时间线、看板四个显式模式。画布中直接落下想法、接着已有卡片思考、点击连接其他卡片；具体交互契约见 interaction.md 第 12、13 节。导航与顶栏默认收起，边缘可临时展开，也可显式固定；刷新尊重固定偏好。

文档模式保留完整列表、筛选、新建与导入；侧栏提供思考空间、文档库、最近打开、随手记与文件夹导航。全库搜索位于底部 Dock，顶栏搜索和 ⌘K 指向同一输入。文档模式不是默认首页。

文档打开后占据完整内容区，导航保持稳定。默认只显示路径、编辑/阅读、保存状态、文档工具与关闭。阅读风格、分享、发布、附件、目录与分栏编辑在文档工具中展开。

Dock 同一位置显式切换搜索 / Agent，各自保留当前页草稿。⌘J 定位 Agent，工作记录向上展开，可单独收起；不另设顶栏聊天入口。加号与“接着想”进入临时记录态，保存后返回原模式，退出记录保留草稿。首屏不展示常驻对话内容、日历、Memo 热力图和覆盖式欢迎页。随手记保留独立工作台；采集、连接器、插件、最近与固定入口可从 Dock 到达。

保留原有文档右键菜单、拖拽、圈选、标签与移动行为。第三方连接、远程同步、AI 消费与外部发布需单独配置和验收，不能用“入口能打开”代替端到端验证。

## 行为约定

- 新建位置跟随当前文件夹，输入「子目录/标题」可在其下创建。已存在的同名文档直接打开，不静默覆盖。
- 导入入口支持 Markdown、文本、HTML；重名时增加数字后缀，保留原文件。其他格式转换和目录导入仍通过原有工具入口提供。
- 编辑停顿 600 ms 后保存，失焦或切换文档时等待当前保存完成。请求捕获提交时的路径和正文；旧响应不得清除后续输入的未保存状态。失败显示提示并保留原文。
- 关闭阅读后可从原有文档标签再次打开。Tab 只用于焦点遍历。
- 列表按目录读取，大目录沿用 `/browse` 的大小上限，通过可选 `offset` 加载后续内容。筛选仅作用于已载入列表，全库搜索在 Dock 可达；纯画布时从底缘唤回。
- 首次空画布引导直接写下第一句，也可导入已有内容；加载错误提供重试；文档模式无搜索结果提供全库搜索入口。
- ≤1024 px 导航覆盖内容、可通过遮罩收起；≤600 px 主操作和视图切换适配单列。浅深色与默认阅读页使用同一套颜色。
- “查看全貌”完整容纳所有可见卡片；小屏允许缩小全局概览，阅读单卡使用聚焦或打开，不能以可读字号下限截断全貌。
- 断网写入失败明确提示“尚未保存”，输入暂留当前页，恢复网络后重试；不得宣称未实现的离线持久化或自动合流。桌面进程内保存兜底保留。

## 验证

自动检查：`cargo test -p thirdc-server --test craft --test palette`、`cargo test -p thirdc-server --lib browse_`、`node --test server/tests/workspace.mjs`。

交互验收：画布默认启动 → Dock 记录 → 接着想 → 连接另一张卡 → 拖动 → 刷新保持位置；搜索 / Agent 草稿分离；搜索不调用模型；纯画布下仍能 ⌥右键执行魔法动作；辅助栏临时唤出镜头不变、固定偏好刷新保留；文档模式的打开文件夹、新建、编辑、关闭、再打开；同名文档保护；重复导入；最近打开；四种内容视图；工作记录展开与关闭；筛选无结果。视觉验收覆盖桌面、窄屏和浅深色。性能检查使用独立示例库，不能以小库结果代替大型真实库基准。

本阶段恢复真实入口与收放、复用原对象动作和预览链路；样稿中的通用 Agent 结果自动落到画布仍属后续阶段，不因 Dock 恢复而宣称已经实现。
