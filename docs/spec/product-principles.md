# Product Principles — 有深度 · 有特色 · 有交互创新 · 有 AI 特性

状态：v1（2026-10-08 定调，源自 2026 竞品全景调研）。本文是 os.md 的产品侧补充：
§10 准入清单管"能不能进"，本文管"怎么做才有灵魂"。五个机制是从 2026 年
付费/开源/AI 三阵营盘点出的最佳实践，全部翻译成基于 ThirdC 现有地基的具体设计；
三条红线是竞品用数年用户流失换来的教训，升格为评审纪律。

## 五个机制 → 五个特性设计

### 1. 视图数据分离（Obsidian Bases）→ `.view` 视图文件　✅ 已落地（2026-10-08）

- **地基**：画布已有 query 节点与看板/时间线渲染；`/browse`、标签筛选齐备。
- **设计**：视图即文件 `Notes/…/团队进度.view`——JSON 声明
  `{source: query|folder|tag, view: kanban|table|calendar, groupBy, filters}`。
  画布渲染 .view 节点，双击进入全屏视图；视图文件本身可 git、可分享、可被 agent 生成。
- **AI 特性**：agent 写视图文件即是"生成结构"——「把 #工作 的 memo 按周分组」
  的产物是一个可审计的 .view 文件，不是一次性渲染。
- **纪律对照**：数据永在 Markdown，视图只是投影（红线 1 的正面解法）。

### 2. 输入-回顾闭环（flomo）→ 回顾模式 + 全局速记 + 微信/邮件入口

- **地基**：Memo Hub 三栏、每条独立文件+tags、桌面 tray、sticky.html、E2EE 备份。
- **设计**：①Hub 中栏顶部「回顾」条——历史 memo 按标签加权抽 3 条重现，
  上滑存档、右滑转正为文档；②桌面全局快捷键速记（托盘已有，加 shortcut）；
  ③`POST /memo/in` webhook（token 鉴权）接微信/邮件转发。
- **AI 特性**：每日洞察只做"联想既有笔记"（联动机制 5 的引用回链），不代答。

### 3. supertags 结构升格（Tana）→ 标签即类型

- **地基**：frontmatter tags 已结构化；OKF 块模型；检查器已有。
- **设计**：类型文件 `Notes/Types/书.tag`（YAML: `fields: [作者,评分,状态,链接]`）。
  文档/memo 挂 #书 后，检查器出现字段表单；字段写回 frontmatter；
  与机制 1 联动：.view 按字段分组排序。
- **AI 特性**：AI 从正文推断未填字段 → 带确认的填充流（可拒绝，逐字段）。
- **纪律对照**：结构由人确认，AI 只做候选（红线 3 的正面解法）。

### 4. 对象级 AI 动词 + MCP（Heptabase）→ 动作栏升级 + MCP 写通道

- **地基**：动作栏已有 翻译/扩写/问 Gemini 等；MCP server 已存在；A2UI 交互直传已通。
- **设计**：①动作栏补结果落点选择（替换/插入/新文档/画布节点/A2UI 卡片）；
  ②MCP 补写工具（put_doc/create_dir/search 已核对，缺的直接补），让 Claude 等
  外部 agent 成为一等公民；③Conflow 生成导图作为标准动词。
- **AI 特性**：AI 是动词不是聊天窗——每个动词有确定落点、可撤销。

### 5. 强制引用回链（NotebookLM）→ AI 答案块引用化

- **地基**：块锚点 `^anchor`、密向量召回（path+score）、A2UI 卡片 `data-doc`、
  `/a2ui/action` 交互直传。
- **设计**：agent 回答的每条结论附来源块卡片（A2UI：`data-doc` + `data-anchor`），
  点击打开文档并滚动到锚点块；agent 工具循环加协议级约束：**有召回必引用，
  无命中必须明说**。
- **交互创新**：答案即画布节点，来源可回原文——反幻觉做成协议约束而非提示词祈祷。

## 三条红线（评审纪律，并入 §10 清单执行）

1. **别动文件真相**（Logseq DB 版之鉴）：格式演进必须无损、可逆、双向兼容；
   任何"迁移存储"提案默认否决，除非能证明旧文件完整可读。
2. **别锁数据、别羞辱免费档**（Roam/Evernote 之鉴）：一键全库导出
   （zip：Notes/ + Assets/ + thirdc.toml）必须是一等命令；导出格式永远不少于
   现有 8 种。
3. **别让 AI 取代用户组织**（Mem 之鉴）：AI 产出必须可溯源（机制 5）、
   可拒绝（机制 3 的确认流）、可撤销（机制 4 的落点选择）；
   结构默认由人定，AI 只做候选与自动化。

## 与 os.md 的关系

os.md 管**能不能做**（架构/真相/边界），本文管**怎么做才有灵魂**（深度/特色/
交互/AI）。新特性提案时两份都过一遍。
