# File Truth Audit — 「文件即真相」完成度排查

日期：2026-10-10 · 触发：用户指出「既然在乎文件，就该支持专业级文件系统操作」。
基准：专业文件管理器（Finder/资源管理器）对文件与文件夹的标准操作集。
宪法：`Notes/`、`Assets/` 是内容真相——**内核不解析 ≠ 不存在**；任何编辑器放进来的东西，应用必须看得见、管得着。

## 二、本次修复（2026-10-10）

1. **非文档文件可见**（最严重违规）：`/browse` 新增 `files[]`（任意扩展名），`/tree` 计数含全部文件；侧栏树渲染「文件叶子」（大小、下载、系统打开、访达、拖拽移动、右键）。
2. **文件夹三件套**：`POST /dir` / `POST /dir/move` / `DELETE /dir`（含路径校验与 16 项回归测试）；UI 右键菜单全接入；非空文件夹走回收站软删除。
3. **原生出口第一步**：`desktop_reveal_path`（访达/资源管理器定位）、`desktop_open_path`（系统默认应用打开），ACL 授权；浏览器端自动隐藏这两项。
4. **拖拽修复**：桌面壳关闭拖放拦截；载荷 `text/thirdc-path|dir` + `text/plain` 兜底。
