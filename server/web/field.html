知识遇到问题，就会显色

整座库按意思铺在一片场上：越像的文档离得越近，区域名由内容自动得出。底部那一行是唯一的入口，提问时相关的知识会从最相关的那篇开始变蓝，答案在它们之间生成，并用线连回每一处出处。文件仍然是普通的 Markdown，位置只是可以随时重算的索引。
